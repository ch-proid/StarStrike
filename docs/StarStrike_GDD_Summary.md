# 🚀 게임 기획안 요약: 스타스트라이크 - 궤도 방어선

**장르:** 하이퍼캐주얼 무기 합성(Merge) + 로그라이트 슈팅 서바이벌
**핵심 재미:** 빠른 손놀림으로 무기를 합성해 압도적 화력을 뿜어내고, 반복적인 죽음을 통해 영구적으로 강해지는 성장 쾌감

---

### 1. 코어 게임 루프
> **전투 진입 (자동 사격 + 수동 합성)** ➡️ **사망 및 재화(우주 스크랩) 획득** ➡️ **격납고에서 영구 능력치 업그레이드** ➡️ **더 높은 웨이브로 재도전**

### 2. 인게임 시스템 (전투 및 합성)
*   **전략적 단일 장착:** 우주선은 자동으로 사격하며, 유저가 달성한 **가장 높은 레벨의 무기 단 1개**만 기체에 장착되어 직관적인 타격감을 줍니다.
*   **DPS 타임어택:** 10웨이브마다 거대 보스가 등장하며, 기체에 닿기 전 파괴해야 하므로 끊임없는 무기 업그레이드를 강제합니다.
*   **분해(휴지통) 시스템:** 머지 게임 특유의 '보드가 꽉 막히는 스트레스'를 없애기 위해, 저레벨 무기를 휴지통에 버리면 인게임 재화를 환급해 줍니다.

### 3. 아웃게임 시스템 (성장 및 해금)
사망 시 획득하는 **우주 스크랩**을 활용해 로비에서 영구적인 성장을 이룹니다.

| 성장 요소 | 상세 내용 | 핵심 포인트 |
| :--- | :--- | :--- |
| **기본 퍽 (Perk)** | 주포 공격력, 최대 체력, 1회용 방어 실드 | 기본 스탯의 점진적 향상 |
| **유틸 퍽 (Perk)** | 상급 무기 드롭 확률, 시작 무기 레벨 강화 | 플레이어가 가장 열광하는 업그레이드 1순위 |
| **무기 테크 해금** | 발칸(단일) ➡️ 레이저(관통) ➡️ 미사일(유도) ➡️ 플라즈마(광역) | 무기 레벨업 시 형태와 이펙트가 완전히 변화 |

### 4. 수익화(BM) 전략
흐름을 끊는 전면 광고보다, 유저가 자발적으로 누르게 만드는 **보상형 광고**에 집중합니다.
*   **위기 탈출 (부활):** 보스전에서 사망 시 "광고 시청 후 체력 50%로 부활" (1회 한정).
*   **재화 증폭 (성장 자극):** 게임 결과 창에서 "광고 시청 시 우주 스크랩 3배 지급".
*   **인게임 지원 (막힘 해소):** 보드가 꽉 찼을 때 "광고 시청 시 무작위 무기 3개 무료 레벨 업".
*   **확실한 캐시카우:** '광고 제거 패키지' 소액 인앱 결제(IAP) 배치.
