# 기술 스택

## 렌더링

- **Three.js**: 원근 카메라(PerspectiveCamera)로 2D 게임플레이에 3D 깊이감을 준다. 위에서 살짝 내려다보는 각도로 카메라를 기울여 입체적인 연출을 만든다.
- 별 배경은 깊이가 다른 여러 겹의 Points 레이어로 패럴랙스(시차) 효과를 낸다.

## 빌드 도구

- **Vite**: 개발 서버와 번들링을 담당한다.
- `npm run dev` — 로컬 개발 서버
- `npm run build` — `dist/`에 배포용 빌드 생성
- `npm run preview` — 빌드 결과 미리보기

## 배포

- **GitHub Pages**: main 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드하고 배포한다.
- 흐름: `npm ci` → `npm run build` → `dist/` 업로드 → Pages 배포.

## 폴더 구조

- `src/main.js` — 씬/카메라/렌더러 초기화, 게임 루프
- `src/starfield.js` — 별 배경 패럴랙스
- `src/ship.js` — 플레이어 우주선(자리표시용)
- `src/camera-fx.js` — 카메라 흔들림·추적 연출
