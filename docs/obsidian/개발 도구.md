# 개발 도구 (2026-08-16)

손으로 검증할 때 판을 빨리 돌리기 위한 관리자 패널이다.

전에는 검증할 때마다 튜닝 값을 임시로 고치고(웨이브 수를 줄이는 식) 되돌렸다.
그 방식은 되돌리는 일을 잊으면 그대로 사고가 된다. 그래서 **정식 기능으로 못 박았다.**
이제 검증용 임시 훅은 넣지 않는다.

## 여는 법

주소 뒤에 `?dev`를 붙인다.

```
http://localhost:4173/?dev
https://<배포 주소>/?dev
```

붙이지 않으면 패널은 **DOM에 아예 만들어지지 않는다.** 코드도 내려오지 않는다.
`main.js`가 `?dev`일 때만 동적 import로 부르기 때문에, 번들에서도 따로 떨어진 조각(3 kB 남짓)이다.

배포 페이지에서도 열린다. 공개 게임이지만 하이퍼캐주얼이라 감출 것이 없고,
실기기에서 바로 만져 볼 수 있는 쪽이 훨씬 이득이다.

## 쓰는 법

오른쪽 가장자리의 작은 **⚙** 버튼을 누르면 세로 패널이 열린다.
폰 프레임 바깥에 놓여 게임 화면을 가리지 않는다. 색은 회색조뿐이라 게임 UI와 섞이지 않는다.

| 버튼 | 하는 일 |
| --- | --- |
| 스크랩 +1,000 | 인게임 지갑에 얹는다. 보드를 곧바로 키울 때. |
| 누적 스크랩 +10,000 | localStorage의 누적 스크랩에 얹고 곧바로 저장한다. |
| 웨이브 클리어 | 지금 웨이브의 적과 남은 스폰 대기열을 비운다. |
| 보스 소환 | 웨이브를 건너뛰고 곧장 보스전으로 간다. |
| 스테이지 +1 | 한 칸 올려 처음부터 다시 깐다. |
| 무적 | 피해와 즉사를 모두 흘려보낸다. 켜지면 칸이 밝아진다. |
| 배속 | 누를 때마다 x1 → x2 → x4로 돈다. 페이싱을 훑을 때. |
| 광고 즉시 완료 | 가짜 광고의 카운트다운을 0초로 만든다. 보상 흐름만 빨리 볼 때([[보상형 광고]]). |
| 즉시 사망 | 무적을 무시하고 죽인다. 사망 → 격납고 흐름을 볼 때. |
| 무기 전부 해금 | 테크 넷을 한꺼번에 연다. 장착은 격납고에서 고른다. |
| 저장 초기화 | `starstrike.*` 키를 전부 지우고 새로고침한다. |

검증이 끝나면 **저장 초기화**로 마무리한다. 부풀린 값이 남지 않게 하기 위해서다.

## 어떻게 이어져 있나

패널은 게임 속을 직접 헤집지 않는다. `game.js`가 열어 둔 **`devApi` 하나만** 쓴다.

```
main.js ──(?dev일 때만)──> dev-panel.js ──> game.devApi ──> 게임 내부
```

`devApi`는 위 표의 열한 가지에 `readState()`(무적·배속·광고 즉시 완료의 지금 값)를 더한 얇은 객체다.
여기 없는 것은 패널도 만질 수 없다. 그래서 패널이 커져도 게임 쪽이 흐트러지지 않는다.

게임 본체에 생긴 자국은 셋뿐이고, 평상시에는 값이 그대로라 일반 플레이에 닿지 않는다.

| 자국 | 평상시 | 하는 일 |
| --- | --- | --- |
| `game.timeScale` | 1 | `gameTime()`이 곱한다. 화면 흔들림 같은 실시간 연출은 그대로 둔다. |
| `game.godMode` | false | `#hurtPlayer`와 `#killPlayer`의 첫 줄에서 걸러진다. |
| `#killPlayer(force)` | false | [즉시 사망]만 true로 부른다. 무적 값 자체는 건드리지 않는다. |

## 파일

| 어디 | 무엇 |
| --- | --- |
| `src/combat/dev-panel.js` | 패널의 모양과 버튼. 스타일도 이 파일이 들고 있다. |
| `src/combat/game.js` | `get devApi()` — 좁은 창구 |
| `src/main.js` | `?dev`일 때만 동적 import |
