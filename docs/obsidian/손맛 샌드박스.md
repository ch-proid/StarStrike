# 손맛 샌드박스 (2026-08-16)

[[기획 검토와 개선안]] 2절의 계획대로, 시스템을 쌓기 전에 타격감부터 확인하려고 만든 무대다.
웨이브도 사망도 합성도 없다. 쏘는 맛과 터지는 맛만 본다.

## 무엇이 들어갔나

### 정적 우주 배경 (`src/space-background.js`)

- 움직이던 별 파티클(`src/starfield.js`)을 지웠다. 시선을 끌기만 하고 깊이감은 주지 못했다.
- 대신 은하수를 코드로 그린다. 2048×2048 캔버스에 심우주 베이스 → 비스듬한 성운 띠 →
  성간먼지 → 별 6천여 개 순서로 쌓고, 텍스처 한 장으로 구워 z = -90 평면에 붙인다.
- 외부 이미지가 없어 배포 용량이 늘지 않는다. 대신 매번 새로 그리므로 실행할 때마다 은하수 모양이 달라진다.
- 사진처럼 보이는 열쇠는 대비를 아끼는 것이다. 성운은 알파 0.05~0.12로 수백 겹, 별도 최대 밝기를 205/255로 눌렀다.
- 블룸 임계값이 0.82라, 배경이 그보다 밝으면 화면이 뿌옇게 뜬다. 마지막에 픽셀을 훑어
  205를 넘는 값은 색조를 지킨 채 눌러 준다(`clampBrightness`).
- 화면 비율이 바뀌면 카메라 절두체 네 모서리를 그 평면에 투영해 크기와 중심을 다시 잡는다.

### 발칸 (`src/combat/vulcan.js`)

- 항상 자동으로 나간다. 초당 10발, 좌우 총구를 번갈아 쏘아 교차 리듬을 만든다.
- 총구 자리는 기체 자식 오브젝트라, 기체가 롤할 때 총구도 함께 기울어진다(`src/ship.js`의 `MUZZLE_LOCAL`).
- 탄은 밝은 시안 심지 + 둘레 글로우 두 겹이라 블룸에 살짝 번진다.
- 발사할 때마다 총구에 두세 프레임짜리 작은 플래시가 뜬다.
- 탄환과 플래시 모두 오브젝트 풀. 지오메트리와 재질은 공유한다.

### 더미 적 (`src/combat/enemies.js`)

- `ships/enemy-interceptor.js`를 그대로 재사용한다. HP 3.
- 화면 위에서 무작위 x로 계속 내려오고, 아래로 벗어나면 회수한다. 동시 5~8기를 유지한다.
- 피격하면 조명을 받는 부품만 흰 재질로 갈아 끼워 두세 프레임 번쩍인다.
  발광 부품(가산 블렌딩)까지 흰색으로 바꾸면 네모난 흰 판이 드러나 제외했다.

### 타격 연출 (`src/combat/effects.js`, `src/combat/sandbox.js` → 지금은 `game.js`)

- 처치 순간: 히트스톱(게임 시간 0.05초 정지) → 화면 흔들림 → 파편 버스트 → 스크랩 드랍.
- 히트스톱은 게임 시간만 멈춘다. 화면 흔들림은 실제 시간으로 돌아가야 멈춘 순간이 더 세게 느껴진다.
- 파편은 주황 14개에 시안을 섞어 폭발의 온도차를 만든다. 수명 동안 흐려져야 해서 재질을 개체마다 따로 둔다.
- 스크랩은 조각 두세 개가 잠깐 흩어졌다가 기체 쪽으로 가속해 빨려 들어온다. 흡수하면 작은 플래시가 뜬다.
- 스크랩 수는 화면 오른쪽 위 HTML 오버레이(`index.html`의 `#hud`)에 표시한다.

## 튜닝 상수

수치는 전부 **`src/combat/tuning.js`** 한 파일에 모았다. 다른 파일에는 흩어 두지 않았다.

| 묶음 | 값 |
| --- | --- |
| `VULCAN` | 발사 간격 0.1초(초당 10발), 탄속 26, 탄 수명 0.9초, 데미지 1, 풀 48, 총구 화염 0.05초 |
| `ENEMY` | HP 3, 속도 1.9~3.1, 스폰 간격 0.6초(모자라면 ×0.3), 동시 5~8기, 풀 12, 판정 반지름 0.62, 번쩍임 0.045초 |
| `HIT` | 히트스톱 0.05초, 흔들림 세기 0.3 / 지속 0.22초 |
| `DEBRIS` | 풀 96, 처치당 14개, 속도 3~9.5, 감속 3.2, 수명 0.22~0.46초, 크기 0.45 |
| `SCRAP` | 풀 48, 처치당 2~3개, 흩어짐 4.2 / 0.26초, 자석 가속도 52, 최대 속도 30, 흡수 반지름 0.55 |

배경 쪽 수치는 `src/space-background.js` 상단에 따로 있다(텍스처 크기, 평면 z, 띠 각도·두께, 별 개수, 최대 밝기).

## 남은 튜닝 항목

실제 화면에서 만져 보며 정할 것들이다.

- 연사 속도와 탄속의 균형. 지금은 초당 10발인데, 더 빠르게 하면 탄이 벽처럼 보일 수 있다.
- 히트스톱 0.05초가 적당한지. 짧으면 안 느껴지고 길면 조작이 끊긴다.
- 흔들림 세기 0.3. 연속 처치 때 화면이 계속 흔들려 어지럽지 않은지 봐야 한다.
- 자석 가속도 52. 지금은 처치 위치에서 기체까지 0.5초 남짓 걸린다.
- 적 판정 반지름 0.62. 기체 실루엣보다 조금 작게 잡았는데, 후하게 줄지 정해야 한다.
- 배경 은하수가 실행할 때마다 달라진다. 마음에 드는 모양이 나오면 난수를 고정할지 정한다.

## 함께 정리한 것

- 전시용 표류 배치(V자 편대, 건쉽, 원반)를 `main.js`에서 걷어냈다. `src/ships/`의 조형 코드는 그대로 남겨 뒀다.
- 보스 정거장은 배경 장식으로 남겼다.
- 스페이스바로 흔들림을 시연하던 임시 조작을 지웠다. 이제 처치가 흔들림을 만든다.

## 그 뒤

이 샌드박스는 [[코어 루프]]로 자랐다. `src/combat/sandbox.js`는 `src/combat/game.js`가 되고,
더미 적은 웨이브 시스템(`enemies.js` + `waves.js`)으로 바뀌었다. 타격 연출은 그대로 재사용한다.
`tuning.js`의 `ENEMY` 묶음은 종류별 `ENEMY_TYPES`로 나뉘었고, 스폰 관련 수치는 `FIELD`와 `WAVE`로 옮겼다.
