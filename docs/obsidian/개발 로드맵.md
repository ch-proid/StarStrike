# 개발 로드맵

## 1단계: 코어 프로토타입

- [ ] 우주선 자동 사격 구현
- [ ] 적 웨이브 스폰 시스템
- [ ] 사망 및 재시작 흐름
- [ ] 기본 카메라와 화면 구성

## 2단계: 머지 시스템

- [ ] 무기 합성 보드 구현
- [ ] 무기 합성(머지) 로직
- [ ] 단일 장착 무기 교체 로직
- [ ] 분해(휴지통) 시스템

## 3단계: 아웃게임

- [ ] 우주 스크랩 재화 시스템
- [ ] 퍽 상점 UI 및 로직
- [ ] 무기 테크 해금(발칸 → 레이저 → 미사일 → 플라즈마)
- [ ] 격납고 로비 화면

## 4단계: 보스 및 밸런스

- [ ] 10웨이브 보스 등장 로직
- [ ] 보스 타임어택 밸런스 조정
- [ ] 웨이브별 난이도 곡선 조정
- [ ] 무기별 밸런스 튜닝

## 5단계: 수익화 및 출시 준비

- [ ] 보상형 광고 4종 연동(부활, 재화 증폭, 막힘 해소, 광고 제거 IAP)
- [ ] 성능 및 안정성 최적화
- [ ] 스토어 등록 자료 준비
- [ ] 출시 빌드 및 QA
