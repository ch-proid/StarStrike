# 프로젝트 컨텍스트

## 개요

스타스트라이크 - 궤도 방어선은 무기 합성과 로그라이트 슈팅을 결합한 모바일 하이퍼캐주얼 게임입니다.
자동 사격으로 싸우며 무기를 합성해 화력을 키우고, 죽을 때마다 얻는 재화로 영구히 강해집니다.
웹 기술(Three.js + Vite)로 만들어 GitHub Pages에 배포합니다.

## 현재 상태 (2026-08-16)

레퍼런스 기반 3D 함대 구현 완료. 플레이어 기체(흰 동체 + 파란 발광 링), 적 4종(요격기·건쉽·원반·고리형 보스 정거장), 블룸 후처리, 화면 비율 대응까지 배포 확인. 기체는 외부 모델 없이 코드로 조형(src/ships/).

움직이던 별 배경을 걷어내고 코드로 그린 정적 은하수 배경으로 바꿨다. 그 위에 손맛 샌드박스를 올렸다. 발칸 자동 사격, 더미 적, 피격 번쩍임·히트스톱·화면 흔들림·파괴 파티클·스크랩 자석까지 동작한다. 자세한 내용은 [[손맛 샌드박스]] 참고.

그 위에 코어 루프를 얹어 게임이 됐다. 스테이지 1개 = 웨이브 10개 + 보스. 적 3종이 웨이브로 밀려오고, 방어선을 넘기면 체력이 깎이고, 보스는 천천히 내려와 시간을 압박한다. 스테이지 클리어와 사망 결과 화면, 누적 스크랩 저장까지 돈다. 자세한 내용은 [[코어 루프]] 참고.
