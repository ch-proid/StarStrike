# 기획 검토와 개선안 (2026-08-16)

[[기획안 정리]]를 바탕으로 코어 루프, 손맛, 수익화를 검토한 결과다.

## 1. 단일 장착 구조의 약점 (가장 중요)

- 문제: 최고 레벨 무기 1개만 쏘면, 보드의 나머지 무기는 전투에 아무 기여를 못 한다. 합성이 "장착 무기가 바뀌는 순간"에만 보상으로 느껴지고, 중간 합성은 밋밋해진다.
- 개선안: 주포(최고 레벨)는 강하게 쏘되, 보드의 나머지 무기 합산 공격력의 20~30%를 보조 화력으로 더한다. 주포 1개의 직관적 타격감은 지키면서, 모든 합성이 곧바로 화력 상승으로 느껴진다.
- **결정 (2026-08-16, 사용자)**: 보조 화력은 실제 탄환이 아니라 수치 보너스(나머지 합산의 25%)로 넣되, 주포의 탄 굵기·연사·색을 연속 보간으로 바꿔 반드시 체감시킨다. 구현은 [[머지 보드]] 참고.

## 2. 손맛 검증 계획

시스템을 쌓기 전에 손맛부터 확인해야 한다. 더미 적 1종 + 발칸 1종만 있는 "손맛 샌드박스"를 먼저 만들어 아래 요소를 튜닝한다.

- [ ] 적 피격 시 흰색 번쩍임
- [ ] 적 처치 시 짧은 멈춤(히트스톱 2~3프레임)과 화면 흔들림
- [ ] 총구 화염, 파괴 파티클
- [ ] 스크랩이 기체로 빨려 들어오는 자석 연출
- [ ] 합성 시 크기 팝 + 파티클

## 3. 코어 루프 페이싱

- **결정 (2026-08-16, 사용자)**: 코어 루프는 스테이지 방식으로 간다. 스테이지 1개 = 웨이브 10개 + 보스, 보스를 잡으면 클리어 화면을 거쳐 다음 스테이지, 죽으면 스크랩을 정산하고 스테이지 1부터 재도전. 구현은 [[코어 루프]] 참고.


- 첫 죽음까지 1~2분. 짧게 죽고 빨리 다시 시작해야 훅이 걸린다.
- 첫 3판은 매판 퍽을 하나씩 살 수 있게 스크랩 곡선을 짠다. "죽어도 강해졌다"를 몸으로 느끼게.
- 보스 등장 전에 권장 화력을 보여줘서, 죽음이 억울하지 않고 "다음엔 이만큼 키워야겠다"로 이어지게 한다.
- 최고 웨이브 기록을 크게 보여준다. 자기 기록 갱신이 재도전의 동력이다.
- 후순위 제안: 보스 처치 후 3개 중 1개 버프 고르기. 로그라이트다운 "런마다 다른 재미"를 싸게 넣는 방법.

## 4. 광고 수익, 웹의 현실

기획의 수익화는 모바일 앱 기준이라 웹에서는 경로가 다르다.

- GitHub Pages에 직접 광고를 붙이기는 어렵다. 구글 H5 Games Ads가 웹 게임 보상형 광고를 지원하지만 승인 절차가 있고, 광고 차단기 때문에 수익의 30~40%가 새는 게 웹의 현실이다.
- 현실적인 길: Poki, CrazyGames 같은 웹 게임 포털 입점. 포털 SDK가 보상형 광고를 제공하고 수익을 나눠 주며, 유저 트래픽도 포털이 가져다준다. GitHub Pages는 개발·테스트·공유용으로 유지한다.
- 광고 제거 결제는 웹 결제 연동 부담이 커서 후순위.
- 설계 지침: 광고 호출을 AdProvider 인터페이스로 감싼다. 지금은 가짜 광고(3초 대기)로 루프만 검증하고, 포털 입점 때 SDK로 갈아 끼운다. 기획의 보상형 광고 4종(부활, 스크랩 3배, 무기 레벨업, 광고 제거)은 그대로 유효하다.

## 6. 결정 기록: 수동 조종 제거와 UI 미니멀 개편 (2026-08-16)

직접 손으로 플레이해 보고 내린 결정이다. 자동 훅으로 굴렸을 때는 보이지 않던 문제들이었다.

**무엇이 문제였나**

- 수동 조준이 합성과 손을 두고 다퉜다. 기체를 몰면 보드를 못 만지고, 보드를 만지면 적을 놓쳤다.
- 첫 3분이 지루했다. 첫 구매까지 너무 오래 걸리고 웨이브 사이가 늘어졌다.
- 스크랩이 떨어진 자리에 방치됐다. 자석이 가속만 줘서 조각이 기체 둘레를 맴돌았다.
- 방어선이 보이지 않아 피해가 이유 없이 들어오는 것처럼 느껴졌다.
- 무기 칸이 무기로 안 보였다. 숫자 타일이라 무엇을 키우는지 알 수 없었다.
- PC에서 레이아웃이 무너졌다. 가로로 넓어지면 전장도 함께 늘어났다.

**결정**

1. **수동 조종을 없애고 자동 조준으로 간다.** 전장 포인터 입력을 전부 걷어냈다.
   기체가 방어선에 가장 가까운 적을 스스로 골라 그 밑으로 간다. 손은 머지 보드에만 둔다.
   이 게임이 파는 것은 조준 실력이 아니라 **합성 판단**이기 때문이다.
2. **스크랩 자석에 반경을 두지 않는다.** 어디서 죽든 전부 기체로 온다.
3. **페이싱을 앞당긴다.** 시작 1초 안에 첫 처치, 4초 안에 첫 구매가 가능하다(실측).
4. **UI는 미니멀로 간다.** 기준은 "적을수록 좋다".
   게임 전체를 세로 한 칼럼(최대 500px)에 가두고, 상단 HUD는 `1-2`와 스크랩 한 줄로 줄였다.
   체력은 방어선에 붙였다. 무엇을 지키는지와 얼마나 남았는지를 한자리에서 읽게 하려는 것이다.
   설명 문장은 전부 지웠다. 못 사면 버튼이 흐려질 뿐, 왜 못 사는지 적지 않는다.
5. **색은 셋만 쓴다.** 강조 시안 · 재화 초록 · 위험 붉은색. 채워진 시안 버튼은 화면에 하나뿐이다.

**바꾸지 않은 것**

보조 화력 공식(1절), 스테이지 구조, 로그라이트 정산은 그대로다. 조작과 표시만 갈아 끼웠다.
